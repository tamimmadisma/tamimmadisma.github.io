# Personal Portfolio Website

## Quick start
1. Open `index.html` in a browser to preview the site.
2. Replace `Your Name`, email, social links, and project links in `index.html`.
3. Replace the `YOUR PHOTO` placeholder with your own image.
4. Put your CV in this folder as `resume.pdf`.
5. Upload the folder to GitHub and enable GitHub Pages for a free public website.

## GitHub Pages
- Create a new public repository.
- Upload `index.html`, `style.css`, `script.js`, and your assets.
- Go to Settings → Pages.
- Choose "Deploy from a branch", select `main` and `/ (root)`.
- Save. GitHub will give you a free `github.io` address.

No paid hosting is required.
